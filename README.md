# 🎯 JobMatch AI

**Score your resume against any job posting, see exactly which skills you're missing, and get AI-written suggestions to tailor it.**

🌐 **Live demo: [jobmatch-ai-mbu5.onrender.com](https://jobmatch-ai-mbu5.onrender.com/)** (free hosting, so the first load can take up to a minute while it wakes up)


Applying to dozens of internships means rewriting your resume for every posting. JobMatch AI does the first pass for you: paste a job description and your resume (or upload a PDF) and it returns a weighted match score, matched and missing skills, keywords to mirror, and concrete edits.

**Example** (a co-op posting vs. a sample resume):
```
Score: 56%  (Moderate match)
Required  ✅ Git, PHP, Python, REST APIs, React   ❌ Datadog, Agile, MySQL / PostgreSQL
Nice-to-have  ❌ Machine Learning, LLMs
Keywords to mirror: observability, relational, databases, ...
```

## ✨ Features
- **Weighted match score**: required skills count double compared with "nice to have" skills, which are detected automatically from headings like *Nice to have*, *Bonus* or *Preferred*
- **Skill extraction** across ~70 technologies (languages, frameworks, cloud, data/AI, practices) with alias handling (`k8s` → Kubernetes, `postgres` → PostgreSQL) and symbol-aware matching, so `Java` ≠ `JavaScript` and `C++`, `C#`, `.NET` and `CI/CD` all work
- **Alternatives handled correctly**: "MySQL or PostgreSQL" is satisfied by either one
- **Missing keywords**: frequent terms from the posting that don't appear in your resume
- **AI suggestions with Claude**: when an `ANTHROPIC_API_KEY` is set, Claude rewrites and strengthens your existing bullets in the posting's language, with a prompt that forbids inventing experience. Without a key (or on any API error) it falls back to rule-based suggestions, so the app always works
- **PDF upload**: text is extracted from resume PDFs with `pypdf`
- **Tested & containerized**: pytest suite, Dockerfile, and GitHub Actions CI that runs the tests and builds the image on every push

## 🧠 How the score works
1. Split the posting into **required** and **nice-to-have** sections
2. Extract skills from each section and from the resume using the alias table in [`app/skills.py`](app/skills.py)
3. Group alternatives ("X or Y") so either one satisfies the requirement
4. Score = matched weight / total weight, where required groups weigh **2** and nice-to-have groups weigh **1**

## ▶️ Run locally
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
# open http://localhost:8000
```

Enable AI suggestions (optional):
```bash
export ANTHROPIC_API_KEY=your_key_here
```

Run with Docker:
```bash
docker build -t jobmatch-ai .
docker run -p 8000:8000 -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY jobmatch-ai
```

Run the tests:
```bash
pip install -r requirements-dev.txt
pytest -q
```

## 🔌 API
| Method | Endpoint | Body |
|---|---|---|
| `POST` | `/api/analyze` | JSON `{ "resume": "...", "job": "..." }` |
| `POST` | `/api/analyze-pdf` | multipart form: `job` (text) + `resume_pdf` (file) |
| `GET` | `/api/health` | – |

Interactive docs are available at `/docs` (Swagger UI, generated by FastAPI).

## 📁 Project structure
```
app/
  main.py      # FastAPI routes, validation, PDF handling
  skills.py    # skill taxonomy, extraction, requirement grouping
  matcher.py   # weighted scoring and keyword analysis
  llm.py       # Claude suggestions + rule-based fallback
static/        # front end (index.html, app.js, styles.css)
tests/         # unit and API tests
```
